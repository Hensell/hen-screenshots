# Identidad pública: Hen Screenshots

Fecha: 6 de septiembre de 2026.

El usuario confirmó **Hen Screenshots** como nombre público después de revisar la coincidencia de HenShots con fotografía deportiva. La dirección visual y verbal de este documento constituye la primera versión de la identidad. El producto sigue en planeación; este material no constituye un lanzamiento.

## Nombre y posicionamiento

| Campo | Definición |
| --- | --- |
| Nombre público | **Hen Screenshots** |
| Escritura | Dos palabras; H y S iniciales en mayúscula |
| Nombre del repositorio | `hen-screenshots` |
| Descriptor en inglés | **App screenshot studio** |
| Tagline | **Your app. Beautifully presented.** |
| Público inicial | Su creador, desarrollando material promocional para sus propias apps |
| Público futuro | Desarrolladores independientes y equipos pequeños que preparan las imágenes de sus apps para Google Play |
| Beneficio central | Crear una serie visualmente coherente y ajustar cada imagen con control sobre su presentación |

El nombre completo debe aparecer en el encabezado, títulos del sitio, README y primera mención. En textos posteriores se puede hablar de “the editor” o “your project”. HenShots queda como antecedente del proceso de nombre, sin utilizarlo como una segunda marca pública.

## Personalidad y voz

- **Cuidada:** composiciones ordenadas, buena tipografía y atención al detalle.
- **Cercana:** lenguaje sencillo y directo, apropiado para una herramienta creada por un desarrollador para su propio trabajo.
- **Práctica:** nombrar la acción, el resultado y cómo recuperar el trabajo cuando algo falla.

El inglés será la referencia para la identidad pública. El idioma de la interfaz puede definirse por separado.

Vocabulario del producto: **project** para el conjunto guardado de una app, **set** para la serie de imágenes, **screenshot** para cada pieza exportable y **capture** para la imagen original importada.

## Sistema visual

**Concepto:** un estudio de composición tranquilo y preciso, con un acento cálido que aporta personalidad.

### Símbolo

Una **H formada por dos marcos verticales de captura unidos por el centro**. Vincula la inicial Hen con la tarea del producto y funciona en una tinta.

- Mantener las proporciones del SVG.
- Usar la versión oscura sobre superficies claras y la clara sobre superficies oscuras.
- Separación mínima alrededor del símbolo: aproximadamente un cuarto de su altura.
- Tamaño recomendado: 24 px o más para el símbolo aislado; 32 px o más para el icono de aplicación.
- La marca principal combina el símbolo con el nombre completo. El icono aislado se reserva para contextos donde el nombre ya es conocido.

### Paleta

| Nombre | Color | Función |
| --- | --- | --- |
| Ink | `#202725` | Texto principal, marca y superficies oscuras |
| Clay | `#B64C35` | Acciones principales, acento de marca e icono |
| Paper | `#F6F4ED` | Fondo principal y texto sobre el acento |
| Sage | `#E3E8DE` | Superficies secundarias y áreas de muestra |
| Muted | `#5E655F` | Texto secundario sobre Paper |

El espacio de trabajo del editor mantendrá superficies neutrales, de modo que las capturas del usuario determinen el color dominante de su composición. La paleta de la marca no limita las plantillas ni los colores exportados por el editor.

Contrastes calculados mediante luminancia sRGB: Ink/Paper 13.84:1; Muted/Paper 5.45:1; Paper/Clay 4.68:1; Ink/Sage 12.23:1. Estas combinaciones superan 4.5:1; cada uso futuro deberá conservar la combinación adecuada.

### Tipografía

**Manrope**, una sola familia para marca, títulos e interfaz.

- Marca: peso 750 y espaciado ligeramente cerrado.
- Títulos: peso 600–650.
- Cuerpo: peso 400–500.
- Etiquetas y acciones: peso 600–650.
- Texto de lectura: 16 px o más; escalas más pequeñas se reservan para etiquetas secundarias y muestras gráficas.

La fuente está incluida localmente junto con su licencia SIL Open Font License. [Origen: Google Fonts](https://github.com/google/fonts/tree/main/ofl/manrope).
