# Hen Screenshots plugin v0.2.2

This release adds Cursor support to the existing local plugin. Codex, Claude Code, and Cursor share the same skill, templates, renderer, and editable project format.

- Includes a Cursor manifest with the Hen logo and skill discovery, plus a repository marketplace catalog.
- Includes local installation and update instructions for Cursor on macOS, Linux, and Windows.
- Adds a Cursor section and a copyable panorama prompt to the website guide in English, Spanish, and Brazilian Portuguese.
- Validates Cursor discovery files, the logo, and matching host versions in the extracted package checks.

Requires Node.js 22.12+ and one-time dependency setup. Rendering stays local. Captions and translations come from the user or agent; the agent provider’s plan and data policies still apply.

OpenAI currently lists v0.2.1. Anthropic remains pending review as checked September 14, 2026. Cursor can use local installation; a marketplace listing is not yet available. Website downloads and official directory approvals are separate.

See [installation instructions](../plugins/hen-screenshots/README.md#install-in-cursor) and [distribution verification](plugin-distribution.md).
